# Política de segurança

## Versões suportadas

Ainda não existe release público suportado. Esta política será atualizada na primeira versão da Community Edition.

## Reportar uma vulnerabilidade

Não publique detalhes sensíveis em issues, discussões ou pull requests.

- Enquanto o repositório estiver privado, mantenedores devem abrir um **draft security advisory** no GitHub.
- Antes da abertura pública, o projeto habilitará **private vulnerability reporting** no GitHub.
- Inclua versão/commit afetado, impacto, forma de reprodução e possíveis mitigações, sem dados reais.

O time confirmará o recebimento e combinará um cronograma de correção e divulgação dentro do próprio advisory. Não há
programa de recompensa financeira anunciado.

Segredos encontrados no histórico ou em uma instalação devem ser revogados/rotacionados; removê-los do arquivo atual
não é suficiente.
