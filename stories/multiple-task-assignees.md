# US-WORK-ITEM-ASSIGNEES-001: vários responsáveis na mesma tarefa

Como gestor, quero atribuir mais de uma pessoa à mesma tarefa para deixar explícita a responsabilidade compartilhada pelo trabalho.

Critérios: a interface permite adicionar e remover responsáveis individualmente, mantém o responsável principal identificado e exibe todos os responsáveis sem substituir os anteriores.
