# Histórias de usuário

Este diretório registra a intenção funcional humana antes da especificação técnica, conforme D67.

- `catalog.json` é o catálogo canônico consumido pelo Context Explorer.
- `_template.md` orienta a escrita de novas histórias antes de a IA criar ou revisar uma spec.
- Histórias não recebem `G-SPEC` nem aprovação individual.
- A spec vinculada transforma as histórias em contrato funcional/técnico e continua exigindo `G-SPEC`.
- Na homologação, observações e comportamentos ausentes geram tarefas rastreáveis para análise da IA.

As histórias atuais foram materializadas dos critérios de aceite já aprovados como migração inicial. Novas mudanças
devem começar pela história, e não pela edição direta da spec.
