# Suporte

## Community Edition

- Bugs reproduzíveis e propostas técnicas: GitHub Issues, após a abertura pública.
- Dúvidas de uso e troca entre a comunidade: GitHub Discussions, após habilitação.
- Vulnerabilidades: siga [SECURITY.md](SECURITY.md), nunca uma issue pública.

Antes de pedir ajuda, consulte a documentação, pesquise issues existentes e informe versão, sistema operacional,
passos de reprodução e logs sem segredos ou dados pessoais.

## Serviços profissionais

Consultoria, treinamento, implantação, suporte e customizações fazem parte do modelo sustentável do Prisma WorkSpace.
O canal comercial e os níveis de serviço serão publicados antes do primeiro release; este arquivo não promete SLA para
o suporte comunitário.
